# Third-party components

The chart uses TradingView Lightweight Charts 4.1.3 (Apache-2.0), installed through npm. Its original license is included in node_modules/lightweight-charts/LICENSE after installation. Attribution and a link to TradingView are displayed below each chart.

Other dependency licenses remain with their npm packages. This source archive does not bundle node_modules or third-party minified chart code.

RadarDEX, Tolly, Sharc and Arcts names are references to independent providers. Their logos are shown only as returned token metadata; this application is not affiliated with those providers. No proprietary frontend code from the reference sites is included.
